## 📖 About

**SkyNet Holidays** is a modern travel and tour booking platform built using **React**, **TypeScript**, **Vite**, **Firebase**, and **Tailwind CSS**.

The platform allows customers to browse domestic and international tour packages while providing an **Admin Dashboard** to manage destinations, packages, blogs, offers, galleries, testimonials, bookings, and website content.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/skynet-holidays.git
```

### 2. Navigate to Project

```bash
cd skynet-holidays
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Firebase

Create a configuration file with your Firebase credentials.

Example:

```ts
apiKey=
authDomain=
projectId=
storageBucket=
messagingSenderId=
appId=
```

---

### 5. Run Development Server

```bash
npm run dev
```

Application will be available at

```
http://localhost:3000
```
